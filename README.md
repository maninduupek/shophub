# ShopHub

A Vue 3 + TypeScript + Tailwind SPA starter project for a DummyJSON-powered e-commerce store.

## Install

```bash
npm install
npm run dev
```

## Project Structure

- `src/components` — reusable UI pieces like `NavBar`, `ProductCard`, and `FilterBar`
- `src/pages` — page-level views such as `HomePage` and `ProductDetailPage`
- `src/types` — strict interfaces for API responses
- `src/store` — Pinia state management for cart or session
- `src/composables` — reusable Composition API hooks
- `src/services` — API client wrappers and fetch helpers

## Notes

This starter includes:
- Vue 3 Composition API
- Tailwind CSS utility styling
- TypeScript interfaces with no `any`
- Router-ready architecture
- Pinia store support
